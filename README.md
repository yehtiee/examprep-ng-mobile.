# ExamPrep NG Mobile

The mobile app for ExamPrep NG, a study app for JAMB (UTME) and WAEC students. Built with React Native (Expo).

## Status

Week 1: project setup and starter screen.
## Build and APK Plan

1. Starter screen: done in Expo Snack (Week 1).
2. Move the starter code into this repo, using Expo on a computer or in a cloud environment.
3. Build the Start Practice screen and the Sign Up / Log In screen (Week 2).
4. Add Focus Mode prompt, then Practice Mode (Week 2 to 3).
5. Build an Android APK with EAS Build (Expo's build service), then test it on a phone (Week 4).
